🛠️ 八、Skill 维护流程

➕ 新增 Skill 时
1. 在 ~/.cursor/skills/<name>/SKILL.md 创建文件
2. 在 00-meta/skill-registry.md 对应分类下添加条目（安装时间、触发词、功能、版本）
3. 重新运行 project-navigator-html 生成最新看板
🔄 更新 Skill 时
1. 修改 ~/.cursor/skills/<name>/SKILL.md 内容
2. 提升版本号（如 v1.0 → v1.1）
3. 在「更新记录」中追加新版本说明
4. 重新生成看板
🗑️ 删除 Skill 时
1. 删除 ~/.cursor/skills/<name>/ 目录
2. 在 skill-registry.md 移除条目
3. 在「更新日志」记录删除事件
4. 重新生成看板
📊 重新生成本看板的命令
下次新会话时，对 AI 说：
用 project-navigator-html 重新生成 Skill 库看板
AI 会读取 00-meta/skill-registry.md 最新数据 + 重新扫描 ~/.cursor/skills/ 目录，生成最新版 HTML。
